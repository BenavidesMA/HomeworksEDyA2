Funciones de Arreglos en JavaScript :

"Length"

Funcion: Sirve para obtener la cantidad de elementos que tiene un arreglo.
Ejemplo:
let frutas = ["Manzana", "Pera", "Uva"];
console.log(frutas.length);

Ejecución:
3

"At"

Funcion: Sirve para obtener un elemento del arreglo mediante su posición, permitiendo también usar índices negativos.
Ejemplo:
let frutas = ["Manzana", "Pera", "Uva"];
console.log(frutas.at(-1));

Ejecución:
Uva

"Concat"

Funcion: Sirve para unir dos o más arreglos y devolver un nuevo arreglo.
Ejemplo:
let a = [1, 2];
let b = [3, 4];
console.log(a.concat(b));

Ejecución:
[1, 2, 3, 4]

"Constructor"

Funcion: Sirve para obtener el constructor que creó el arreglo.
Ejemplo:
let numeros = [1, 2, 3];
console.log(numeros.constructor);

Ejecución:
ƒ Array() { [native code] }

"CopyWithin"

Funcion: Sirve para copiar una parte de los elementos dentro del mismo arreglo.
Ejemplo:
let numeros = [1, 2, 3, 4];
console.log(numeros.copyWithin(0, 2));

Ejecución:
[3, 4, 3, 4]

"Entries"

Funcion: Sirve para obtener un iterador con los índices y valores del arreglo.
Ejemplo:
let frutas = ["Manzana", "Pera"];
console.log([...frutas.entries()]);

Ejecución:
[[0, "Manzana"], [1, "Pera"]]

"Every"

Funcion: Sirve para comprobar si todos los elementos del arreglo cumplen una condición.
Ejemplo:
let numeros = [2, 4, 6];
console.log(numeros.every(n => n % 2 === 0));

Ejecución:
true

"Fill"

Funcion: Sirve para reemplazar todos o algunos elementos del arreglo por un valor determinado.
Ejemplo:
let numeros = [1, 2, 3, 4];
console.log(numeros.fill(0, 1, 3));

Ejecución:
[1, 0, 0, 4]

"Filter"

Funcion: Sirve para crear un nuevo arreglo con los elementos que cumplen una condición.
Ejemplo:
let numeros = [1, 2, 3, 4];
console.log(numeros.filter(n => n > 2));

Ejecución:
[3, 4]

"Find"

Funcion: Sirve para encontrar el primer elemento que cumple una condición.
Ejemplo:
let numeros = [5, 10, 15];
console.log(numeros.find(n => n > 8));

Ejecución:
10

"FindIndex"

Funcion: Sirve para encontrar el índice del primer elemento que cumple una condición.
Ejemplo:
let numeros = [5, 10, 15];
console.log(numeros.findIndex(n => n > 8));

Ejecución:
1

"FindLast"

Funcion: Sirve para encontrar el último elemento que cumple una condición.
Ejemplo:
let numeros = [5, 10, 15, 20];
console.log(numeros.findLast(n => n > 8));

Ejecución:
20

"FindLastIndex"

Funcion: Sirve para encontrar el índice del último elemento que cumple una condición.
Ejemplo:
let numeros = [5, 10, 15, 20];
console.log(numeros.findLastIndex(n => n > 8));

Ejecución:
3

"Flat"

Funcion: Sirve para convertir arreglos anidados en un arreglo de menor profundidad.
Ejemplo:
let numeros = [1, [2, 3], [4, 5]];
console.log(numeros.flat());

Ejecución:
[1, 2, 3, 4, 5]

"FlatMap"

Funcion: Sirve para aplicar una función a cada elemento y aplanar el resultado.
Ejemplo:
let numeros = [1, 2, 3];
console.log(numeros.flatMap(n => [n, n * 2]));

Ejecución:
[1, 2, 2, 4, 3, 6]

"ForEach"

Funcion: Sirve para ejecutar una función una vez por cada elemento del arreglo.
Ejemplo:
let frutas = ["Manzana", "Pera", "Uva"];
frutas.forEach(fruta => console.log(fruta));

Ejecución:
Manzana
Pera
Uva

"Includes"

Funcion: Sirve para comprobar si un elemento existe dentro del arreglo.
Ejemplo:
let frutas = ["Manzana", "Pera", "Uva"];
console.log(frutas.includes("Pera"));

Ejecución:
true

"IndexOf"

Funcion: Sirve para obtener el índice de la primera aparición de un elemento.
Ejemplo:
let frutas = ["Manzana", "Pera", "Uva"];
console.log(frutas.indexOf("Pera"));

Ejecución:
1

"Join"

Funcion: Sirve para unir todos los elementos del arreglo en una cadena de texto.
Ejemplo:
let frutas = ["Manzana", "Pera", "Uva"];
console.log(frutas.join(", "));

Ejecución:
Manzana, Pera, Uva

"Keys"

Funcion: Sirve para obtener un iterador con los índices del arreglo.
Ejemplo:
let frutas = ["Manzana", "Pera", "Uva"];
console.log([...frutas.keys()]);

Ejecución:
[0, 1, 2]

"LastIndexOf"

Funcion: Sirve para obtener el índice de la última aparición de un elemento.
Ejemplo:
let numeros = [1, 2, 3, 2];
console.log(numeros.lastIndexOf(2));

Ejecución:
3

"Map"

Funcion: Sirve para crear un nuevo arreglo aplicando una función a cada elemento.
Ejemplo:
let numeros = [1, 2, 3];
console.log(numeros.map(n => n * 2));

Ejecución:
[2, 4, 6]

"Pop"

Funcion: Sirve para eliminar y devolver el último elemento del arreglo.
Ejemplo:
let frutas = ["Manzana", "Pera", "Uva"];
console.log(frutas.pop());

Ejecución:
Uva

"Push"

Funcion: Sirve para agregar uno o más elementos al final del arreglo.
Ejemplo:
let frutas = ["Manzana", "Pera"];
frutas.push("Uva");
console.log(frutas);

Ejecución:
["Manzana", "Pera", "Uva"]

"Reduce"

Funcion: Sirve para reducir todos los elementos del arreglo a un solo valor.
Ejemplo:
let numeros = [1, 2, 3, 4];
console.log(numeros.reduce((a, b) => a + b, 0));

Ejecución:
10

"ReduceRight"

Funcion: Sirve para reducir los elementos del arreglo a un solo valor comenzando desde el final.
Ejemplo:
let letras = ["A", "B", "C"];
console.log(letras.reduceRight((a, b) => a + b, ""));

Ejecución:
CBA

"Reverse"

Funcion: Sirve para invertir el orden de los elementos del arreglo.
Ejemplo:
let numeros = [1, 2, 3];
console.log(numeros.reverse());

Ejecución:
[3, 2, 1]

"Shift"

Funcion: Sirve para eliminar y devolver el primer elemento del arreglo.
Ejemplo:
let frutas = ["Manzana", "Pera", "Uva"];
console.log(frutas.shift());

Ejecución:
Manzana

"Slice"

Funcion: Sirve para obtener una parte del arreglo sin modificar el arreglo original.
Ejemplo:
let numeros = [1, 2, 3, 4];
console.log(numeros.slice(1, 3));

Ejecución:
[2, 3]

"Some"

Funcion: Sirve para comprobar si al menos un elemento del arreglo cumple una condición.
Ejemplo:
let numeros = [1, 3, 4];
console.log(numeros.some(n => n % 2 === 0));

Ejecución:
true

"Sort"

Funcion: Sirve para ordenar los elementos del arreglo.
Ejemplo:
let numeros = [3, 1, 2];
console.log(numeros.sort());

Ejecución:
[1, 2, 3]

"Splice"

Funcion: Sirve para agregar, eliminar o reemplazar elementos dentro del arreglo.
Ejemplo:
let frutas = ["Manzana", "Pera", "Uva"];
frutas.splice(1, 1, "Mango");
console.log(frutas);

Ejecución:
["Manzana", "Mango", "Uva"]

"ToLocaleString"

Funcion: Sirve para convertir los elementos del arreglo en una cadena usando las reglas de formato de la configuración regional.
Ejemplo:
let numeros = [1000, 2000];
console.log(numeros.toLocaleString("es-CO"));

Ejecución:
1.000,2.000

"ToString"

Funcion: Sirve para convertir el arreglo en una cadena de texto.
Ejemplo:
let frutas = ["Manzana", "Pera", "Uva"];
console.log(frutas.toString());

Ejecución:
Manzana,Pera,Uva

"Unshift"

Funcion: Sirve para agregar uno o más elementos al inicio del arreglo.
Ejemplo:
let frutas = ["Pera", "Uva"];
frutas.unshift("Manzana");
console.log(frutas);

Ejecución:
["Manzana", "Pera", "Uva"]

"Values"

Funcion: Sirve para obtener un iterador con los valores del arreglo.
Ejemplo:
let frutas = ["Manzana", "Pera", "Uva"];
console.log([...frutas.values()]);

Ejecución:
["Manzana", "Pera", "Uva"]
